# Weather Diary - Дневник погоды

**Автор:** Капаева Ригина Ришатовна
**GitHub репозиторий:** https://github.com/ilseyar1210-UI/weather-diary2

## Описание

Weather Diary — это графическое приложение на Python (Tkinter) для ведения дневника погоды. Позволяет добавлять записи о погоде, фильтровать их по дате и температуре, а также сохранять данные в JSON-файл.

## Установка и запуск

1. Убедитесь, что установлен Python 3.7+
2. Скачайте файл `main.py` из репозитория
3. Запустите в терминале:
   ```bash
   python main.py
